# ShopEase – E-commerce Store

A simple yet complete e-commerce web application built with **Django**, developed as part of the **CodeAlpha Internship (Task 1)**.

Users can browse products by category, search, view product details, add items to a cart, register/login, place orders and track their order history. Admins can manage products, categories and order status from the Django admin panel.

## Tech Stack
- Python, Django
- SQLite
- HTML, CSS (Django templates)

## Features
- Product listing with categories and search
- Product detail page with related products
- Session-based shopping cart (add / update / remove)
- User registration, login and logout
- Checkout (Cash on Delivery) with automatic stock update
- Order history and order detail pages
- Admin panel for managing products and orders
